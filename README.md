# Агент для подбора junior-вакансий

Мини-проект для разбора стажировок и junior-вакансий. Агент читает резюме и критерии, собирает вакансии из SuperJob, валидирует и дедуплицирует данные, ранжирует вакансии и создает Markdown-отчет.

## Что реализовано

- Источник вакансий: SuperJob API.
- Резервные источники: Remotive и локальный SQLite fallback.
- База данных: SQLite `data/app.db`.
- LLM-слой: Groq API для извлечения профиля кандидата и объяснения топ-5.
- Обычная логика: валидация, дедупликация, скоринг, сортировка, отчет и лог.
- Итоговые файлы: `output/report.md` и `output/run.log`.

## Запуск

```powershell
cd D:\vs_code_projects\Agent
python -m src.bot --dry-run --resume data/sample_resume.md --criteria criteria.md
```

## Где смотреть

- `output/report.md` — итоговый Markdown-отчет.
- `output/run.log` — trace действий агента.
- `data/app.db` — SQLite-база с памятью и локальным fallback.
- `criteria.md` — критерии кандидата.
- `data/sample_resume.md` — простое демо-резюме.

## Agentic workflow

1. Groq извлекает структурированный профиль из резюме и критериев.
2. SuperJob API возвращает вакансии по нескольким русскоязычным запросам.
3. Код валидирует строки, удаляет дубли и считает score.
4. Groq объясняет топ-5: почему подходит, что совпало, что смущает и какой следующий шаг.
5. Отчет фиксирует рейтинг, причины отсева и trace.

