# Резюме

Ищу стажировку или junior-позицию как Python разработчик, Backend разработчик или разработчик API. Хочу писать backend-сервисы, интеграции с внешними API и Telegram-ботов.

## Навыки

- Python, FastAPI, asyncio
- SQL, PostgreSQL, SQLite
- REST API, JSON, разработка API, интеграции с внешними API
- Telegram Bot, aiogram
- Git, базовый Docker
- LLM-интеграции через Groq API, prompt engineering

## Предпочтения

- Формат: удаленно, гибрид или офис в Москве/Санкт-Петербурге
- Уровень: стажер, стажировка, junior, junior+
- Интересны backend, автоматизация, API, Telegram Bot, AI-функции
- Не подходят неоплачиваемые стажировки, senior/lead роли и вакансии с требованием 3 года опыта
